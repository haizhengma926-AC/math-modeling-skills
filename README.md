适用于：全国大学生数学建模竞赛、美赛、各类校级/省级数模比赛、课程建模作业、科研数据分析建模场景。

## 🤖 万字AI提示词核心能力

本项目配套的**万字AI数学建模提示词**，经过专项优化，完美适配各类大模型（GPT、deepseek、GLM、Claude等），解决数模竞赛核心痛点：

- **精准审题拆解**：自动拆解赛题需求、识别题型、锁定建模方向，避免跑题偏题
- **智能模型选型**：根据赛题场景推荐最优数学模型（预测、优化、聚类、评价、微分方程等）
- **算法代码生成**：一键生成可直接运行的Python/Matlab代码，支持调试、优化、报错修复
- **数据处理可视化**：数据清洗、拟合分析、图表绘制、结果可视化全套AI辅助
- **高分论文撰写**：规范论文结构、专业句式输出、逻辑梳理、格式排版、查重优化
- **摘要高分优化**：针对数模竞赛评分标准，专属摘要润色，突出创新点与核心成果
